# dish-photos/

Drop dish photos here. The website automatically picks them up.

## Filename rule

Each dish maps to a filename based on its slug. See **SLUGS.txt** for the
full list of dish → filename mappings.

```
Kung Pao Chicken         →  kung-pao-chicken.jpg
Hot 'N' Sour Soup        →  hot-n-sour-soup.jpg
Chef's Special Soup      →  chefs-special-soup.jpg
Wokin Special Beef       →  wokin-special-beef.jpg
```

## Format

- **Extension:** `.jpg` (lowercase)
- **Size:** landscape, ~800×600 or larger (4:3 ratio looks best)
- **Weight:** under ~300 KB each so the page loads fast (use any
  online compressor like squoosh.app or tinyjpg.com)

## Until you upload

Cards fall back to the universal Chinese food spread
(`Assorted_Chinese_food_set.jpg.webp`) so every card always shows
real Asian food.
